Definir Produto

Cada campo usa um tipo TypeScript diferente. O compilador valida os dados automaticamente.

Objeto Tipado

interface Produto {{'{'}}
nome: string = "{{ produto().nome }}"
preco: number = {{ produto().preco }}
emEstoque: boolean = {{ produto().emEstoque }}
{{'}}'}}
Valores Computados
Preço formatado: {{ precoFormatado() }}
Status: {{ produto().emEstoque ? 'Disponível' : 'Indisponível' }}
