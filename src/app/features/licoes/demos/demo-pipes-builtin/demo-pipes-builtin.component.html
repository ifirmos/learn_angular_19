1 | date formatar datas
@for (fmt of dataFormatos; track fmt) {
{{ fmt }} → {{ data() | date: fmt : '' : 'pt-BR' }}
}

| date:'formato':'timezone':'locale' — locale pt-BR requer registerLocaleData.

2 | currency formatar moedas
Valor:
BRL → {{ valor() | currency:'BRL':'symbol':'1.2-2' }}
USD → {{ valor() | currency:'USD' }}
EUR → {{ valor() | currency:'EUR':'code' }}
3 | number casas decimais
Número:
'1.0-0' → {{ numero() | number:'1.0-0' }}
'1.2-2' → {{ numero() | number:'1.2-2' }}
'1.4-6' → {{ numero() | number:'1.4-6' }}

Formato: 'minInt.minDec-maxDec'

4 | uppercase / titlecase transformar texto
uppercase → {{ texto() | uppercase }}
titlecase → {{ texto() | titlecase }}

Pipes são puros por padrão: só reexecutam quando o valor de entrada muda.
