<p> {{'{{'}} expressão {{'}}'}} </p>

Tudo entre {{'{{ }}'}} é avaliado como JavaScript e renderizado no HTML. Interaja e observe o código ao lado atualizar.

1

Variável

signal → template

Um signal expõe seu valor sendo chamado como função no template.

→ {{ nome() || '…' }}
TS 
nome = signal('{{ nome() }}');
HTML 
<p>{{'{{ nome() }}'}}</p>
<!-- renderiza: "{{ nome() }}" -->
2

Expressão

a() + b()

Operações JavaScript são avaliadas diretamente em {{'{{ }}'}}.

+
→ {{ soma() }}
TS 
a    = signal({{ numA() }});
b    = signal({{ numB() }});
soma = computed(() => this.a() + this.b()); // = {{ soma() }}
HTML 
<p>{{'{{ a() + b() }}'}}</p>
<!-- renderiza: {{ soma() }} -->
3

Método

texto().método()

Métodos JavaScript podem ser chamados diretamente no template.

.toUpperCase() {{ texto().toUpperCase() || '…' }}
.length {{ texto().length }}
TS 
texto = signal('{{ texto() }}');
HTML 
<p>{{'{{ texto().toUpperCase() }}'}}</p>
<!-- "{{ texto().toUpperCase() || '…' }}" -->

            
<p>{{'{{ texto().length }}'}}</p>

            
<!-- {{ texto().length }} -->
