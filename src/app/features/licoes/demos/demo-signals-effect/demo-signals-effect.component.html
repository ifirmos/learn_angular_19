3 untracked() ler sem dependência
effect(() => {
rastreado const t = tema();
não rastreado const v = untracked(() => volume());
});

untracked() lê um signal sem criar dependência. O effect não re-executa quando esse signal muda.

4 quando usar effect()
✓sincronizar com localStorage
✓acionar analytics / logs
✓manipular DOM externo (Canvas, charts)
✗derivar valores → use computed()
✗escrever em signals dentro do effect

Regra: effect() é para side effects externos, não para lógica de estado.
