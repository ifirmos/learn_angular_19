1 signal(initialValue) criar + ler
const nome = signal '{{ nome() }}'
nome() → '{{ nome() }}'

Sinais são invocados () para ler o valor. Em templates isso cria uma dependência reativa.

2 .set(novoValor) substituir
preco() → {{ preco() }}

.set() substitui o valor completamente. Use quando você tem o valor final pronto.

3 .update(fn) transformar
contador() → {{ contador() }}
@for (h of historico(); track $index) { {{ h }} }

.update(v => v + 1) recebe o valor atual e retorna o novo — ideal para incrementos/toggles.

4 computed(() => expr) somente leitura
preco() → {{ preco() }}
dobro() → {{ dobro() }}

computed() retorna um Signal derivado e somente leitura. Recalcula automaticamente quando preco() muda.
