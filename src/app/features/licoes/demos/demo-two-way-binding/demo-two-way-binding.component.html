1 [(ngModel)] açúcar sintático
nomeModel → '{{ nomeModel }}'

O [(banana-in-a-box)] combina [property binding] e (event binding) em um só.

2 [ngModel] + (ngModelChange) equivalente explícito
textoManual → '{{ textoManual }}'

Útil quando você precisa interceptar o valor antes de atribuir: (ngModelChange)="onMuda($event)"

3 type="number" two-way numérico
idadeModel → {{ idadeModel }}
typeof → {{ idadeModel.constructor?.name ?? 'number' }}

Angular converte para number automaticamente com type="number".

4 <select [(ngModel)]> select two-way
selecionado: {{ nivelModel }}

Funciona com <select>, <textarea> e inputs customizados que implementam ControlValueAccessor.
